
# Learning Style Explorer (LSE)

Learning Style Explorer is a web application designed to help students explore and understand their preferred learning styles.

## Features

- Learning style questionnaire
- Login and signup pages
- Six visual themes
- Reusable interface components
- Responsive design
- Interactive form fields and dropdowns

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Git and GitHub

## Project Structure

The application uses separate folders for its pages, shared components, themes, and assets.

Shared components are reused across pages to maintain consistent styling and behaviour.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the application's home HTML page in a browser.
4. Navigate through the application.

## Development

This project is being developed as part of a web application development assessment.

The focus is on clean, readable code, reusable components, responsive design, and a user-friendly interface.
